# train_delay_project
An analysis of the delays of different train operators in the United Kingdom, and advice about the actions to take to improve them

My first step was to find the train delay data from the ORR data portal, and then I normalised this data into two tables, one for the train operators, and one for all delay records.
Before working on the data, I had to clean the data to allow myself to analyse the data as needed, (etc there were inconsistencies with the casing of the train operators)
